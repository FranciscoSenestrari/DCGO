# Design System Specification: DCGO Visual Identity

## 1\. Overview \& Vision

The **DCGO** visual identity is a futuristic, cyberpunk-inspired digital brand system. It bridges 8-bit retro pixel aesthetics with high-fidelity 3D volume, holographic glowing interfaces, and dual-tone chromatic contrast (Cyan/Blue vs. Neon Orange).

\---

## 2\. Color Palette

### Primary Colors

* **Cyber Cyan / Electric Blue**: `#00D2FF`

  * *Usage*: Primary digital glow, left shield panel, bottom metallic text gradient.
* **Neon Orange / Amber**: `#FF6B00`

  * *Usage*: Secondary UI panel, right shield background, accent glow.
* **Crimson Red / Glitch Pink**: `#FF2A4B`

  * *Usage*: Top text outline, inner core energy glow, primary visual highlights.

### Dark \& Metallic Neutral Colors

* **Deep Matrix Charcoal**: `#0A0E17`

  * *Usage*: Main background canvas, digital code overlays.
* **Carbon Fiber Grey**: `#2A2E3D`

  * *Usage*: Text bevel texture, back panel drop shadows, structural frames.

\---

## 3\. Typography \& Logo Geometry

### Logo Typography: "DCGO"

* **Style**: 3D Isometric Pixelated / Block Typography.
* **Bevel \& Depth**: Multi-layered extrusions with carbon fiber patterns and top crimson inner light.
* **Glitch Effects**: Slight horizontal offset line disruptions across letters `D`, `E`, `G`, `O`.

### UI \& Body Fonts

* **Primary Code / Monospace**: `JetBrains Mono` or `Fira Code` (for code backgrounds and matrix streams).
* **UI Display Headers**: `Orbitron` or `Rajdhani` (bold, geometric, uppercase).

\---

## 4\. Key Graphic Elements

1. **Holographic Glass Shields**:

   * Isometric rotated semi-transparent cards.
   * Left: Blue tinted code sheet (`#00D2FF` @ 30% opacity).
   * Right: Orange tinted code sheet (`#FF6B00` @ 30% opacity).
2. **Background Matrix / Binary Grid**:

   * Out-of-focus futuristic data center / cyberspace nodes.
   * Floating HUD micro-text, circuit traces, and subtle starfield particle effects.
3. **Lighting \& Glow Effects**:

   * Central radial bloom effect behind text.
   * High-contrast emissive edges on all pixel block borders.
